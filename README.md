## React + Vite
# Authentication App

A modern authentication system built using React (Vite), Express, and SQLite. This application features secure user authentication with JWT, protected routes, and professional UI styling.

# Features

User Registration & Login with Form Validation (Formik & Yup)

Secure Authentication using JWT

Protected Routes (Dashboard access restricted to authenticated users)

Responsive UI with professional styling

Logout functionality

Error handling and user feedback messages

# Technologies Used

Frontend: React (Vite), Formik, Yup, React Router

Backend: Express.js, SQLite, bcrypt.js, jsonwebtoken (JWT)

Styling: Modern CSS with enhanced UI design

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.
